# Career Agent

An AI-powered career assistant that searches multiple internship and entry-level job sources, filters relevant roles, ranks opportunities, and generates reports.

## Features

- Search jobs from multiple websites
- Filter internships and entry-level roles
- Rank opportunities based on relevance
- Generate reports
- Modular architecture for adding new job sources
- Ready for OpenAI integration

## Installation

```bash
git clone https://github.com/yourusername/career-agent.git
cd career-agent
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
